PYTHON 3.12

Desde la raíz del proyecto, inicia el servidor con el entorno virtual y abre la dirección que imprime la terminal.

En una copia nueva, instala requirements-deploy.txt y ejecuta scripts/prepare_deployment.py (o requirements.txt + notebooks 01 y 02). El servidor utiliza el modelo congelado.

INSTRUCCIONES RÁPIDAS

Guía de uso

La reserva de prueba ya está cargada. La gráfica principal, la cámara CNC y el dial semicircular reaccionan en vivo a cada observación sintética.

  1. Controla la reproducción

    Usa Iniciar simulación para avanzar automáticamente o Siguiente para analizar caso por caso. El selector Ritmo ajusta la pausa entre observaciones.

  2. Explora la gráfica suavizada

    Alterna entre Rotación, Torque, Aire, Proceso y Desgaste desde los botones superiores o haciendo clic en cualquier sensor; pasa el cursor sobre la curva para inspeccionar cada UDI.

  3. Observa el banco CNC y el diagnóstico

    La cámara virtual refleja RPM, torque, desgaste y temperatura, mientras el panel de clasificación muestra el veredicto, el dial de carga y los contadores TN/TP/FP/FN.

  4. Exporta tus resultados

    Exportar CSV descarga todos los registros procesados de la sesión completa con predicciones, etiquetas reales y latencias.

Una predicción sin falla no garantiza ausencia de falla. Para detalles completos, descarga el manual.
