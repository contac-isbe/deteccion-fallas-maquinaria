# AI4I 2020

Archivo: `raw/ai4i2020.csv`.

Fuente oficial: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

Referencia: AI4I 2020 Predictive Maintenance Dataset. (2020). UCI Machine Learning Repository. https://doi.org/10.24432/C5HS5C

Licencia del dataset: Creative Commons Attribution 4.0 International (CC BY 4.0).
https://creativecommons.org/licenses/by/4.0/

El CSV se conserva sin modificaciones. Contiene 10 000 registros y 14 columnas.
SHA-256: dc6630cd9b1f0f853922fad78a1b6436570d3f1ec863f1dd5c4340ac56bc8a8e

Las entradas utilizadas son Type, Air temperature [K], Process temperature [K], Rotational speed [rpm], Torque [Nm] y Tool wear [min]. La salida es Machine failure. Los identificadores y las etiquetas de tipos de falla no se utilizan como entradas.
